This project implements a **fully connected neural network classifier from scratch** using a tiny automatic differentiation engine inspired by Andrej Karpathy’s *micrograd*.

No PyTorch.  
No TensorFlow.  
No ML libraries.

Everything — forward pass, gradients, and backpropagation — is written manually using scalar operations.
